## Testing Accounts

### User

Use this account to test normal user features:

- Login / Logout
- OTP verification
- Forgot Password
- Home page
- Product list
- Product details
- Pagination

- Email: `USER_TEST_ACCOUNT`
- Password: `USER_TEST_PASSWORD`

### Admin

Use this account to test administration features, especially CRUD:

- Category CRUD
- Product CRUD
- Add / Edit / Delete Product
- Product image upload
- Category management

- Email: `ADMIN_TEST_ACCOUNT`
- Password: `ADMIN_TEST_PASSWORD`

> **Note:** Please use the Admin account when testing CRUD features.
